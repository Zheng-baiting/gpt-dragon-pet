# 龙娘 · GPT Dragon Pet

一只白发紫瞳的小龙娘，陪你写代码，也陪你偶尔发呆。

![龙娘工作状态](assets/pet-preview.png)

Windows 独立桌宠，参考 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，
保留白龙娘的角、尖耳、结形发饰和无嘴巴设定。它不依赖 DeepSeek Harness。

## 已实现

- 透明无边框小窗口；只在角色不透明像素上接收鼠标，透明处穿透。
- 八种姿态和四帧行走：待机眨眼、思考、抱电脑工作、等待、挥手庆祝、惊讶、睡觉、散步。
- 拖拽、弹簧跟手、甩抛、边缘反弹；轻轻放下时停在原地。
- 工作间：尺寸、置顶、散步、气泡、减少动态效果、动作预览。
- 托盘恢复、右键菜单、位置记忆、单实例运行。
- 可选地只读连接一个明确选择的 Codex 会话，按结构化事件切换动作。

动作由姿态切换和程序运动组合完成；目前不是每个动作都有完整视频或逐帧动画。

## 运行

需要 Windows 10/11 与 Node.js 24+。

```powershell
npm start
```

使用 Windows 自带的 WPF 透明窗口和 Node.js，无需下载 Electron 或安装 npm 依赖。
Windows 可以直接双击 `启动龙娘.vbs`，也可以运行 `启动龙娘.cmd` 查看错误信息。
`安装依赖.cmd` 仅检查 Node.js 并准备本地物理模块，不安装系统组件。
无需管理员权限。没有自动启动项；退出可在角色右键菜单或系统托盘中操作。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击角色 | 摸摸、挥手和一句本地台词 |
| 按住拖动 | 移动角色；快速甩出后惯性反弹 |
| 右键角色 | 打开工作间、休息、散步或退出 |
| 双击托盘图标 | 打开工作间 |
| 工作间 → 选择会话 | 连接一个 Codex 会话 JSONL 文件 |

手动预览动作会暂时优先于会话状态；“回到自动状态”恢复联动。睡眠需手动唤醒。

## 数据与边界

设置、位置和本地运行状态保存在项目的 `.state/`，不进入 Git；构建和检查文件在 `.generated/` 与 `work/`。
会话连接只允许 Codex `sessions/` 或 `archived_sessions/` 内明确选择的 JSONL 文件；
按有限大小增量读取，仅使用事件类型、时间和工具名判断状态，不保存或上传聊天正文。
不读取凭据、不发起模型请求、不修改 Codex 设置、不监听网络端口。

状态字段依赖 Codex 的本地日志格式。日志不可用时显示未连接，不用 CPU 占用或聊天关键词猜测任务状态。
首次启动没有默认会话；每台电脑需自行选择。

## 开发与检查

```powershell
npm test
npm run smoke
```

单元检查覆盖偏好校验、显示器边界、生命周期事件、动态效果和原项目物理计算。
进程级检查覆盖所选会话联动、手动睡眠优先、参数过滤、甩抛边界和退出保存。
桌面冒烟检查创建实际 WPF 窗口，验证精灵加载、工作间控件和状态切换，渲染预览；输出保存在 `work/qa/`。

当前提供源码启动方式，尚未制作免 Node.js 的安装包。跨屏拖动支持负坐标；甩抛限制在当前屏幕的工作区。
