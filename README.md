# GPT 白龙娘 · 鲸鱼娘原版底座

直接使用 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的透明视频渲染、右键菜单、点击反馈、拖拽弹簧、甩抛与多屏几何。这里维护 GPT 白龙娘角色、动作配置、视频导入和 Codex 插件入口。没有继续使用旧版 WPF 桌宠。

**当前可用：小只 Q 版角色、24 fps 正式待机、五种点击回应、拖拽悬空姿态、两种步行、六种工作状态、哈欠、屈膝行礼、下蹲、小憩、惊醒、摇摆和受惊，以及原版拖动与甩抛。** 22/106 个动作已有素材：十八段约十秒，四段为完整五秒短版，另有两段独立基础动画。启动不需要视频服务或 FFmpeg。当前没有自动读取 Codex 会话，也没有实现动画状态联动。

按用户要求恢复原版 **640×360、24 fps**：22段正式动作和2段基础动画统一规格，不再五倍补帧。保留原始视频、此前调色和局部动作修正；120 fps版本可从Git历史恢复。尺寸降低后细线清晰度相应降低。

视频切换在原版双缓冲上增加首帧呈现检查，并让旧视频在原有 180 毫秒淡化期间继续播放；快速切换会取消过期加载。运行副本使用隔离加法合成，避免交叠中点透明度降到约75%；素材读取在原版路径校验后补齐字节范围响应，避免重播解码错误。不同生成片的角色姿态与细节仍有差别，尚不能保证任意动作之间无缝衔接。

以正式待机为色彩基准，已校正明暗差异最大的六段：小憩、下蹲、惊醒、摇摆、行礼和哈欠。固定色彩曲线减轻偏白或偏暗，保留原动作、24 fps 和透明背景；除待机外的21段首尾分别以9帧运动过渡接到共同待机站姿，不额外停住；主体动作和源片差异仍保留。不同源片的造型、画风与清晰度差异仍需逐段处理。2026-10-22归档已从五秒480p源的短版换为Seko十秒720p源：完整查看纸张、整理收好并消散，经过固定调色和独立星点的安全区修正，仍输出原版360p/24fps。

2026-10-22新增十秒“被吓一跳”：受惊瞪眼、胸前举手、呆毛弹起、僵直微颤、放松吐舌并复位。豆包Mini每日免费生成，固定调色、共同站姿和原生实播验收通过；当前仍缺84个动作。

## 本地运行

Windows x64、Node.js 24+。所有依赖都安装在项目目录，原来的 GPT-Niang 插件不受影响。

```powershell
npm ci
npm run setup
npm run runtime:install
npm start
```

双击 `预览GPT娘.vbs` 可以隐藏终端启动。角色会眨眼、轻微呼吸，点击随机播放开心跃动、害羞惊讶、傲娇生气、挠痒咯咯笑或元气挥手，拖动时切到悬空姿态。步行动作接入原版屏幕移动逻辑；也可右键「动作 → 移动」点播原地漂浮踏步或螃蟹走路。窗口右键菜单和拖动来自上游。`npm run stop` 关闭本项目窗口；`npm run status` 查看状态。

右键「动作 → 工作状态」可点播思考冒泡、忙碌点按、清点归档、原地踱步张望、雀跃庆祝和垂头叹气冒汗；「动作 → 小动作 → 哈欠连天」可播放哈欠。小憩、惊醒、下蹲、行礼和摇摆也已接入原版分类菜单与随机动作链。工作状态目前用于点播，尚未接入 Codex 会话事件。

导入已检查的成品时需要已有的 FFmpeg 与 FFprobe；处理源视频另需已有 Python，见制作文档。若 FFmpeg 不在 PATH，可仅对当前终端设置路径：

```powershell
$env:GPT_PET_FFMPEG = '你的已有FFmpeg目录\ffmpeg.exe'
npm run media:import -- '待机呼吸休闲' 'work/pipeline/待机呼吸休闲/video-24fps.webm'
```

Electron 固定为上游使用的 43.3.0，下载与缓存都在项目内。官方下载过慢时，可在当前终端使用上游默认镜像再执行安装：

```powershell
$env:GPT_PET_ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
npm run runtime:install
```

运行时不在 Windows 底部任务栏显示图标；透明区支持点击穿透。Chromium 配置、缓存、日志、DSH_HOME 全部隔离在 `.runtime/`。不会创建登录启动项，不会全局安装软件，不会读取账户、额度或聊天，也不会自动调用模型。

## Codex 插件

执行 `安装GPT娘插件.cmd`。安装器只打包连接配置、插件说明和图标三个文件，连接本地项目；安装后需要保留本项目目录。插件初始化不会自动弹出角色。

- `get_gpt_pet_status`：查询运行和视频制作状态。
- `show_gpt_pet`：默认显示 Q 版预览，自动接入已导入的正式动作；传入 `preview: false` 请求完整动作模式，缺视频则说明原因。
- `hide_gpt_pet`：关闭本项目窗口。

当前没有自动跟随 Codex 开关、登录启动或会话动画联动。上游独立模式的余额、碎碎念、对话、通知依赖 DSH，当前不可用；相应菜单操作会返回上游的不可用说明，不会代为连接模型。

## 制作动作视频

见 [视频制作与导入](docs/VIDEO.md)。原项目的 106 个逐动作配方与四个后期脚本已接入，替换角色设定后仍沿用原版动作时序和站姿规范。`assets/actions.json` 列出全部入口及上游动作名；`config/gpt.json` 保留原版分类、权重和运动参数，鲸鱼专属动作名称改为白龙版本。

```powershell
npm run media:list
npm run media:prompt -- '待机呼吸休闲'
npm run media:recipes
npm run media:process -- '待机呼吸休闲' 'D:\已有素材\idle.mp4' --chroma 0x00FF00
npm run media:import -- '待机呼吸休闲' 'work/pipeline/待机呼吸休闲/video-24fps.webm'
npm run check
npm test
```

预览启动：`npm start`，自动接入已导入的正式待机、点击、拖拽、移动和分类动作，无需等待整库完成。当前点击池五种回应和工作池六种状态已齐全，拖拽、两种移动及哈欠也已接入；正式待机或点击素材缺失时使用对应基础动画。余额等有固定顺序的事件池仅在该池素材齐全时接入，避免状态错位。完整动作模式启动：`npm run start:full`；其配置引用的视频须先齐全。素材当前 `22/106`，缺少素材不会回退显示鲸鱼娘。

基础动画来自 8 帧待机和 6 帧招手的生成图，使用双向光流生成运动中间帧，呼吸位移使用连续亚像素形变。它们仍是两段基础动作。源图在 `assets/sheets/`，成品在 `assets/basic/`；重建依赖与命令见 [角色制作记录](docs/CHARACTER.md)。普通运行无需重建。
