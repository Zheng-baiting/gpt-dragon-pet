# GPT 白龙娘角色定稿

本项目按用户提供的两张参考图认领白发紫瞳的 GPT 龙娘作为非官方项目形象。第一张用于长裙、翼膜、龙尾与结饰细节；第二张只参考最上方 ChatGPT 一排，不包含其他角色或手机界面。

制作工具：已获用户同意的内置 OpenAI 图像生成工具。输出经本地 Pillow 统一为 1920×1080 RGBA 透明画布，角色脚底约在画布高度 92%，头顶与两侧留白。原生成图保留在本地工作区和工具输出中，不进入公开仓库；用户原始附件也不进入仓库。

定稿提示词摘要：

> Adult white-haired lavender-eyed ChatGPT dragon woman from the user references; white horns, pointed ears, flowing white/lavender long gown and draped sleeves, lavender wing membranes, fluffy scaled white dragon tail, small silver knot ornaments. Normal adult anime proportions, elegant friendly face, refined dimensional cel shading. One full-body three-quarter-front neutral standing pose, whole gown and extremities in frame, generous clear padding. Same character identity as the references. Transparent alpha, no scenery, floor, text, watermark, phone UI, duplicate pose, blue maid costume or whale tail. This is an unofficial fan character.

`assets/gpt-reference.png` 是动作视频的统一人物参考。`config/preview.json` 对应的预览视频由此图静态编码，仅用于验证原版显示和交互，不作为正式动作。

人物属于用户指定的同人拟人表达，不能据此声称 OpenAI 官方背书、合作或官方吉祥物身份。素材仅作个人、非商业同人用途；原参考画作与标识相关权利属于其各自权利人。
